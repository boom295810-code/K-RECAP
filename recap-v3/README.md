# K RECAP v3 — Chinese Drama → မြန်မာ Dubbing Tool

ဗီဒီယို ထည့်လိုက်တာနဲ့ အလိုအလျောက်:

1. **အသံထုတ်** — ဗီဒီယိုထဲက အသံကို ffmpeg နဲ့ ထုတ်
2. **စာသားထုတ်** — AssemblyAI နဲ့ တရုတ်စကားပြောကို အချိန်တွေနဲ့တကွ စာသားထုတ် (ပြောသူ A/B/C ခွဲ)
3. **မြန်မာပြန်** — Gemini နဲ့ ပြောဆိုသလို မြန်မာစာပြန် (လိုင်းတစ်ခုချင်း အချိန်ထဲ ဆံ့အောင် တိုတို)
4. **အသံသွင်း** — Edge TTS (မြန်မာ Thiha / Nilar, အခမဲ့) သို့မဟုတ် Gemini TTS
5. **ညှိ + Video ထုတ်** — မြန်မာအသံ တစ်လိုင်းချင်းကို မူရင်းစကားပြောတဲ့ အချိန်မှာ တိတိကျကျ နေရာချ၊
   ရှည်နေရင် နောက်လိုင်းမစခင် ဆံ့အောင် pitch မပြောင်းဘဲ အမြန်နှုန်းတင် (အများဆုံး x1.6 ပြင်လို့ရ)၊
   မူရင်းအသံကို အသံတိုးပြီး နောက်ခံအဖြစ် ရော → MP4 + SRT

## Editor
- လိုင်းတိုင်း — မြန်မာစာ ပြင်၊ အချိန် ပြင်၊ ပြောသူ/အသံ ပြောင်း၊ 🎙 အသံပြန်ထုတ်၊ 🌐 ပြန်ဘာသာပြန်၊ ▶ မူရင်းနားထောင်
- ⚠️ အနီ = မြန်မာစာရှည်လို့ မဆံ့ → စာတိုအောင်ပြင်ပြီး 🎙
- "🎬 ပြင်ထားတာတွေ အသံပြန်ထုတ်ပြီး Video ထုတ်" — ပြင်ထားတဲ့ လိုင်းတွေပဲ အသံပြန်ထုတ်ပြီး video အသစ်ထုတ်
- ⚙️ **API Keys / Settings** — AssemblyAI key နဲ့ Gemini key ထည့်တဲ့ box (browser ထဲမှာပဲ သိမ်း)

## Run
```
START-K-RECAP.bat        (Windows — ပထမဆုံးအကြိမ် package တွေ အလိုအလျောက် install)
```
or
```
cd recap-v3/server
npm install
npm start                # http://localhost:5002
```
Node.js 18+ လိုပါတယ်။ ffmpeg ကို package နဲ့အတူ ပါပြီးသား။ Project ဖိုင်တွေ `recap-v3/server/data/` မှာ သိမ်းတယ်။

## ဖုန်းကနေ သုံးရန် (Render free hosting)
1. GitHub မှာ PR ကို merge လုပ်ပါ (`render.yaml` က main branch ပေါ်ရောက်ဖို့)။
2. https://render.com/deploy?repo=https://github.com/boom295810-code/K-RECAP ကိုဖွင့် → GitHub နဲ့ sign in → `APP_PASSWORD` မှာ ကိုယ်ပိုင် password ထည့် → **Apply**။
3. ၅-၁၀ မိနစ်လောက်နေရင် `https://k-recap-xxxx.onrender.com` link ရပါမယ်။ ဖုန်း browser နဲ့ဖွင့်ပြီး password ရိုက်ထည့်ပါ (username က ဘာရိုက်ရိုက်ရ)။

Free plan မှတ်ချက်: RAM 512MB ဖြစ်လို့ မိနစ် ၁၀ အောက် video တွေ သင့်တော်တယ်။ ၁၅ မိနစ် မသုံးရင် အိပ်သွားပြီး ပြန်ဖွင့်ရင် ၁ မိနစ်လောက် စောင့်ရတယ်။ Server restart ဖြစ်ရင် project ဟောင်းတွေ ပျက်တယ် (MP4 ကို ပြီးတာနဲ့ ဒေါင်းထားပါ)။
